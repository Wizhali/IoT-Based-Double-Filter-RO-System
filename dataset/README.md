
# Dataset

## Overview

This directory contains the dataset used for the machine-learning component of the IoT-Based Double-Filter RO System.

The dataset is used to analyze water-quality parameters and support the RNN-based predictive analysis component.

## Water-Quality Features

The intended input features include:

* pH
* TDS
* Turbidity
* Temperature
* Conductivity

## Dataset Preparation

Before model training, the dataset may require:

1. Data cleaning
2. Missing-value handling
3. Feature selection
4. Data normalization
5. Reshaping for RNN input
6. Training and testing split
